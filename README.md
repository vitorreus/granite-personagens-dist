# Personagens — plugin do Granite (versão compilada)

Fichas de personagem para histórias no [Granite](https://github.com/vitorreus/granite): aparência, imagens de referência, personalidade, história, relações e aparições, em arquivos `.character`.

Este repositório contém **só a versão compilada** do plugin, pronta para instalar. O código-fonte é mantido em outro repositório.

## Instalar
- Pela tela **Plugins sugeridos** do Granite, ou
- manualmente: `git clone https://github.com/vitorreus/granite-personagens-dist.git ~/.granite/plugins/personagens`

Depois, em ⚙ → **Plugins**, ative **Personagens** e recarregue.

## Usar
Crie um arquivo `.character` pela árvore de arquivos (**Novo arquivo** → `Akari.character`); a ficha abre automaticamente.

Versão 0.1.0 (fonte 3c43326).
